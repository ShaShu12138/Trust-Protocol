# 第一天试玩

启动：`npm run dev -- --host 127.0.0.1 --port 5173`

打开 http://127.0.0.1:5173/，选择“重新体验第一天”。

- 接电话 → 打开邮件 → 取消交易 → 接听 112 → 完成警方对话。
- 路线一：自己打开浏览器 → 搜索 Nova / Nova银行 / 银行 → 银行官网 → 联系我们 → 比较发件域名。
- 路线二：打开 Nova 银行 → 查看近期和待处理交易。
- 返回邮件 → 转发给警方 → 选择一个理由 → 发送。
- 所有理由均可发送，不即时提示对错。稍后 112 回电，给出对应反馈，继续后结束。
- 可重玩并故意选错误理由，检查反馈差异。也可不查证就发送。

目前仅包含第一天；搜索内容和转发均为本地游戏逻辑。
