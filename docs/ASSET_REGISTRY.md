# Trust Protocol — Asset Registry

## Purpose

This registry records every production visual asset currently approved for the project. It documents origin, usage rights, AI assistance, intended use, and review status.

All assets listed here were created specifically for Trust Protocol. No third-party stock assets or real brand materials are included.

## Status labels

- **Approved core** — ready to use as a foundational asset.
- **Approved provisional** — usable in the prototype, but may change after visual or usability testing.
- **Source master** — high-resolution source retained for future exports.
- **Runtime export** — optimised file intended for the application.

### Prompt specifications

The production prompt family used the following invariant art direction:

```text
Polished editorial 2D game illustration; calm modern European banking-research prototype; deep navy, muted teal, warm cream, and restrained coral; tactile paper grain; soft geometric forms; reassuring rather than fear-based; no readable text, letters, numbers, real logos, watermark, or photorealistic software screenshot.
```

Per-asset subjects were: open verified mail; independent website comparison; secure transaction review; verified callback; calm home-workspace onboarding; orderly evidence connections; layered security checks; five fraud-scenario chapter scenes; and four behaviour-based endings. Character-expression prompts additionally required strict identity preservation and changing only the facial expression.
